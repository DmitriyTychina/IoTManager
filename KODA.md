# KODA.md — Контракт проекта IoTManager

> Этот файл — указатель для инструмента KODA. Полный контракт репозитория — в **AGENTS.md**.

## О проекте

Прошивка «умного дома» для **ESP8266 / ESP32 / BK7231N** (C++, PlatformIO)
и веб-конфигуратор прошивок **magicIoTm** (Python Flask).
Вся документация — на русском.

## Краткая памятка

- Сборка прошивки: `pio run -e <плата>` (по умолчанию `esp32s2_4mb`).
- Панель: `cd tools/magicIoTm && run.bat` → http://127.0.0.1:5005
- Правила работы ассистента — в `AGENTS.md` (обязательны к выполнению, включая этот файл).
